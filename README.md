# ZTorrent Desktop (Electron)

Полноценный BitTorrent клиент с киберпанк-интерфейсом.

![ZTorrent](preview.png)

## Быстрый старт

### Способ 1: Готовый .exe
Скачайте `ZTorrent.exe` из раздела Releases.

### Способ 2: Сборка

#### Требования
- **Node.js** >= 16 ([скачать](https://nodejs.org/))

#### Сборка

```bash
# 1. Перейдите в папку electron
cd electron

# 2. Установите зависимости
npm install

# 3. Соберите .exe
npm run build

# Или просто запустите build.bat
build.bat
```

Готовый .exe появится в папке `dist/`.

## Возможности

- ✅ Добавление по magnet-ссылке или .torrent файлу
- ✅ Загрузка с прогрессом в реальном времени
- ✅ Автоматическая раздача (seeding)
- ✅ Пауза/Продолжение
- ✅ Отображение скоростей и пиров
- ✅ **Ratio система** - отслеживание раздачи
- ✅ Киберпанк интерфейс (чёрно-зелёный)
- ✅ Кастомный title bar с кнопками

## Ratio система

| Ratio | Статус |
|-------|--------|
| 🟢 > 1.0 | Отлично - вы раздаёте больше чем качаете |
| 🟡 0.5-1.0 | Нормально |
| 🔴 < 0.5 | Нужно больше раздавать |

## Использование

1. Запустите `ZTorrent.exe`
2. Нажмите "Добавить" или перетащите .torrent файл
3. Вставьте magnet-ссылку
4. Следите за загрузкой!
